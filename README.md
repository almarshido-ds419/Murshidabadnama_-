# Murshidabadnama_-
A Bengali historical book on Murshidabad, the Nawabi era, Siraj-ud-Daulah, and the Battle of Plassey, based on historical sources and research. (মুর্শিদাবাদের উত্থান, নবাবি যুগ, সিরাজউদ্দৌলা ও পলাশীর যুদ্ধের ইতিহাস—বহু ঐতিহাসিক দলিল, গ্রন্থ ও গবেষণার ভিত্তিতে রচিত একটি বাংলা ইতিহাসগ্রন্থ।)
